## Documentation consulted (facts only, no code or text copied)

* "The Mobiclip Formats" — public technical write-up by quatric (GitHub gist, linked from the
  [mobipeg](https://github.com/quatric/mobipeg) project). Used to cross-check facts that had already been
  derived from file analysis: flags byte = sync counter, seek-table layout, 4096-byte blocks, frame/sync
  rules and the 3D layout byte.
* IMA/DVI ADPCM step-size and index tables (public standard).

## External programs (optional, not bundled)

* **FFmpeg** (`ffmpeg` executable) is called as a separate process by `moflex encode` / the GUI to decode and
  scale arbitrary input videos. Raw `.yuv` input does not need it. Its license applies to the copy you install.

## What is *not* used

* No Nintendo/Actimagine SDK, Mobiclip encoder or decoder binaries, libraries, keys or documentation.
* The proprietary encoder was never disassembled or decompiled.
* No game files or sample media are distributed; tests that need sample movies read them from a folder you
  provide (`MOFLEX_SAMPLES`).
